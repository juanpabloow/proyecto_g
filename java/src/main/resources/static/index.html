DAC

Detector de Alertas de Contratación

Señales de posible soborno o extorsión en la contratación pública, cada una con la evidencia que la originó.

Exportar reporte (CSV)

DAC no acusa a nadie. Una alerta es una hipótesis que una persona debe verificar con los contratos que la originaron (R-4).

Cargar contratos

Archivo CSV con las columnas numero_contrato, entidad, contratista, funcionario, monto, fecha. Cargar el mismo archivo dos veces no duplica nada.

Se revisa en el navegador que sea un .csv, que no esté vacío y que no supere 10 MB antes de enviarlo.

Cargas de esta sesión

Cada archivo analizado queda aquí con su resumen. Volver a cargar el mismo archivo da 0 nuevos: lo que ya está guardado no se repite (HU-07).

    —contratos en la base
    —nuevos en esta carga
    —alertas activas
    —filas para revisar

    Resultados

    Filtra las alertas de reincidencia y fraccionamiento por contratista, funcionario o entidad.

    El mismo contratista con el mismo funcionario en 2 o más contratos, aunque sean de entidades distintas. Los nombres escritos distinto (mayúsculas, tildes, puntos) se reconocen como el mismo (HU-05).

    Un contratista con varios contratos pequeños en la misma entidad, dentro de una ventana de días, que juntos alcanzan el tope de cuantía (HU-03).

    Filas de la última carga que no se convirtieron en contrato, con el motivo. El resto del archivo se analizó igual (HU-04).

    Contratos repetidos que traían datos distintos. Se conservó la primera versión; aquí ves qué cambió para decidir cuál es la correcta (HU-06).
